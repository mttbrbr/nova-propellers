# Nova Propellers provenance

This document records the provenance review for the source-only public
distribution of Nova Propellers.

## First-party material

- Copyright holder: `mttbrbr`.
- Development context: personal project, developed without an employer,
  client or university claim reported by the author.
- Authorship: original work produced by the author with assistance from
  OpenAI Codex. No source code was knowingly copied from repositories,
  tutorials or third-party answers.
- Git history reviewed on 2026-08-26: four commits, all attributed to
  `mttbrbr`; only source, configuration and documentation files have been
  committed.
- Public exact-phrase searches for distinctive solver comments and docstrings
  found no matching implementation. This is a due-diligence check, not a
  guarantee of uniqueness.

OpenAI's service-specific terms note that code-generation output may be
subject to third-party licenses. Algorithmic modules must therefore be
reviewed against public implementations and documented mathematical sources
before a public release. Any code with unclear provenance must be rewritten
from the documented method rather than published under an assumed license.

## Data and media

- No external airfoil coordinate files, experimental polar datasets, meshes,
  audio or video are tracked in Git. The repository screenshot is first-party
  media recorded in `docs/media/PROVENANCE.md`.
- Built-in polar values are synthetic demonstration data generated by this
  project. They are not XFOIL, CFD or wind-tunnel measurements and are not
  suitable for validation.
- UIUC/XFOIL `.dat` support is an import format only. Users are responsible
  for ensuring that files they import may be used for their intended purpose.
- Future screenshots and recordings must show only Nova's interface and use
  no third-party music, stock media, logos or unlicensed fonts.

## Distribution boundary

The first public release distributes source code and build instructions only.
It does not distribute prebuilt container images, Python wheels, npm bundles,
databases, imported datasets or generated geometry. Dependencies downloaded by
package managers remain under their respective licenses.

Publication is blocked until the following are true:

- [x] every tracked file is covered by an SPDX declaration;
- [x] dependency versions are locked and their licenses inventoried;
- [x] no unresolved `UNKNOWN`, GPL or AGPL direct runtime dependency remains;
- [ ] algorithmic source review is complete;

- [ ] tests, build and license checks pass from a clean checkout.
