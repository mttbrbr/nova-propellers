# Desktop icon provenance

`icon.png` is a 1024×1024 raster (rsvg-convert, 2026-11-11) of
`docs/media/brand/nova-icon.svg`, the NOVA mark on a rounded tile. The mark is
drawn geometrically by `tools/brand/make_logo.py` (three rounded ring
segments; thickness 40 % of the radius, 45° gaps, 70 % corner rounding) from
parameters chosen by the project author. It contains no third-party material
and is released under the repository's Apache-2.0 license.
