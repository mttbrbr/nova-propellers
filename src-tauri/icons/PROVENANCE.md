# Desktop icon provenance

`icon.png` is an original asset generated for Nova Propellers with the OpenAI
image generation tool on 2026-08-30. The prompt requested a modern,
vector-like three-blade propeller mark in charcoal, silver and cyan, without
text, brands or third-party references. The generated image was resized to
1024×1024 RGBA for Tauri packaging.

The project author claims this output as first-party project media under the
repository's Apache-2.0 license. No external logo or stock asset was used as
input.
