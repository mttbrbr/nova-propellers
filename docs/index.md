# NOVA

:::{container} nova-eyebrow
Documentation
:::

:::{container} nova-lead
NOVA is an open-source, local-first workbench for designing and exploring traditional propellers
and rotors: geometry, low-order aerodynamic analysis, project storage and STL export in one
interface. It is alpha software: results are not certified.
:::

:::{container} nova-cards
- [User guide](guide/installation.md)
  Install NOVA, start it, learn the concepts and find your way around the interface.
- [Technical manual](technical/architecture.md)
  Architecture, rotor models, block workflows, verification and validation. Also available as a PDF.
